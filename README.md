# Internship AI Agent 🤖

An LLM-powered assistant designed to help students with internship preparation through personalized role recommendations, resume improvement, LinkedIn outreach, and structured AI career roadmaps.

## 📌 Project Overview

Finding relevant internships and preparing strong applications can be challenging for students. The Internship AI Agent uses a Large Language Model (LLM) and task-based routing to provide structured assistance for common internship and career-preparation tasks.

The project demonstrates how Python, prompt engineering, and LLM APIs can be combined to build a task-oriented AI assistant.

## ✨ Features

- **Internship Recommendations:** Suggests internship roles and platforms based on a student's interests and profile.
- **Resume Improver:** Rewrites resume content to improve clarity, grammar, and professional presentation.
- **LinkedIn Message Generator:** Drafts professional outreach messages for recruiters and hiring teams.
- **AI Career Roadmap:** Generates structured learning plans based on a user's career goal.
- **Task-Based Routing:** Routes user requests to the relevant function using keyword-based rules.
- **Structured LLM Responses:** Uses system prompts to guide the assistant toward specific, actionable responses.

## 🛠️ Tech Stack

- Python
- Google Colab
- OpenAI Python SDK
- OpenRouter API
- OpenAI GPT-4o mini model via OpenRouter
- Prompt Engineering

## ⚙️ How It Works

1. The user submits a career-related request.
2. The agent examines the request using keyword-based routing.
3. The relevant function sends the task to the LLM through the OpenRouter API.
4. The model generates a response based on the supplied instructions.
5. The result is returned to the user.

For unrecognized requests, the assistant uses a general LLM response path.

## 🚀 Getting Started

### Option 1: Run in Google Colab

1. Open `Internship_AI_Agent.ipynb` from this repository.
2. Open the notebook in Google Colab.
3. Create an OpenRouter API key through [OpenRouter](https://openrouter.ai/).
4. In Colab, open **Secrets** and add a secret named `OPENROUTER_API_KEY`.
5. Enable notebook access to that secret.
6. Run the notebook cells in order.
7. Enter a request to try the available assistant features.

### Option 2: Install the dependency locally

Install the required Python package:

```bash
pip install openai
```

The notebook is designed for Google Colab. To run it locally, adapt the API-key setup to use an environment variable or another secure secret manager.

## 🧪 Example Requests

```text
Suggest internships for a second-year CST student interested in AI and ML.

Improve my resume: built a chatbot.

Write a LinkedIn message to a recruiter for a software internship.

Give me a learning roadmap to become an AI engineer.
```

## 🔐 Security and Responsible Use

- Never commit API keys, access tokens, or other secrets to GitHub.
- Store the OpenRouter API key in Colab Secrets or another secure secret manager.
- Review generated resume content before using it in an application.
- Do not accept generated metrics, technologies, or achievements unless they are supported by your actual experience.
- Internship recommendations are suggestions, not verified live vacancies. Check the employer's official website for current openings and eligibility.

## ⚠️ Current Limitations

- Task selection uses keyword-based routing rather than autonomous LLM tool selection.
- Internship recommendations are generated by the LLM; the project does not currently retrieve or verify live vacancies.
- Response quality depends on the user input and the model's output.

## 🎯 Project Objective

To explore practical LLM application development by building a task-oriented AI assistant that supports students during internship preparation and early career planning.
